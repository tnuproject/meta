# Support

META is pre-release software without support guarantees.

- **Questions and bugs:** [issues](https://github.com/tnuproject/meta/issues). Include
  the output of `meta info` and, on FreeBSD, `meta doctor`.
- **Vulnerabilities:** privately, as described in [SECURITY.md](SECURITY.md).
- **Hardware results:** the hardware report form.
- **FreeBSD itself:** the [Handbook](https://docs.freebsd.org/en/books/handbook/) and
  [forums](https://forums.freebsd.org/). Please do not report META problems there.

A command that exits with status 69 is not implemented; that is not a bug.
